# NearZoop — design prototype

High-fidelity screen designs for the NearZoop app, built with Next.js, React and
Tailwind CSS.

## Run it

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). The splash is the app screen
itself — full-bleed orange, with the content held to a mobile column on desktop.

## Screens

- `/` — splash screen

## Brand

The NearZoop mark lives in `src/components/brand/logo-mark.tsx`. App icons and
lockups are in `public/brand/`, with usage notes in `public/brand/README.md`.
